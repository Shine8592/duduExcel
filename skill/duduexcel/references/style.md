# 样式与配色规范

> 财务建模配色属行业通行惯例（投资银行建模标准），此处为独立表述，
> 与 `duduexcel/styling.py` 的 `STYLE_SEMANTICS` 保持单一事实源。

## 字体语义

| 颜色 | RGB | 含义 | 使用场景 |
|---|---|---|---|
| 蓝 | `0000FF` | 硬编码输入 / 情景开关 | 用户可直接修改的假设值 |
| 黑 | `000000` | 公式 | 所有计算单元格 |
| 绿 | `008000` | 跨工作表引用 | `=Assumptions!B5` |
| 红 | `FF0000` | 跨文件引用 | 引用了别的工作簿 |
| 黄底 | `FFFF00` | 关键假设 / 待填写 | 需要用户填的格子 |

**为什么重要**：读者一眼就能分辨"哪些能改、哪些是算出来的"。
建模错误最常见的来源就是有人误改了公式单元格。

## 数字格式码

| 用途 | 格式码 | 说明 |
|---|---|---|
| 人民币整数 | `¥#,##0` | 单位写进表头：`营收（¥万元）` |
| 人民币两位 | `¥#,##0.00` | 精确金额 |
| 零显示短横 | `¥#,##0;(¥#,##0);-` | 负数用括号 |
| 百分比 | `0.0%` | **值必须存小数** |
| 倍数 | `0.0x` | 估值倍数如 12.5x |
| 千分位 | `#,##0` | 通用计数 |
| 日期 | `yyyy-mm-dd` | |

### 百分比陷阱（最常犯）
- 存 `0.15` + 格式 `0.0%` → 显示 `15.0%` ✅
- 存 `15` + 格式 `0.0%` → 显示 `1500.0%` ❌

## 结构规范

1. **每个假设独占一个带标签的单元格**，被引用而非内联：
   - 好：`=B5*(1+$B$6)`
   - 坏：`=B5*1.05`
2. **公式在所有预测期保持一致**。一行里某个单元格被单独编辑过，是最常见的静默错误。
3. **分母必须防零**：`=IFERROR(A5/B5, 0)` 或 `=IF(B5=0, 0, A5/B5)`。
4. **单位写进表头**，不要写进每个单元格。

## 中文场景

- 字体：微软雅黑（默认）/ 宋体（正式文档）
- 列宽：中文按 2 个字符宽度计算（`apply_chinese_style` 已自动处理）
- 表头：加粗 + 浅灰底 + 居中 + 冻结首行
